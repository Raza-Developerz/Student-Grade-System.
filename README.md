# 🎓 Student Grade System - Java

A simple and efficient Java console application to calculate student grades for7 subjects. It takes total and obtained marks, calculates the percentage, and assigns a grade from A+ to F.

![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)

## 📖 About
This project was created to automate the manual process of calculating student results. The user enters marks for 7 subjects, and the program instantly calculates total marks, percentage, and final grade.

## ✨ Features
- Input marks for 7 subjects
- Calculates Total Marks
- Calculates Percentage automatically
- Assigns Grade (A+ to F)
- Simple console-based interface
- Error handling for invalid inputs

## 📊 Grading Criteria
| Percentage | Grade |
| :--- | :--- |
| 90% - 100% | A+ |
| 80% - 89% | A |
| 70% - 79% | B |
| 60% - 69% | C |
| 50% - 59% | D |
| Below 50% | F (Fail) |

> You can change this table according to your own logic in `StudentGradeSystem.java`
